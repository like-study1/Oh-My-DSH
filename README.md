## 为什么是 Oh-My-DSH

**01 · 生态雷达，全量扫描** — 每 8 小时自动抓取 GitHub `dsh-plugin` topic 全量快照（700+ 仓库），新增、删除、改名一目了然。

**02 · 人工策展，不是冷冰冰的列表** — 自动抓取之外，每个精选条目都经过人工分类与简介校对：类型、活跃度、语言、Star 一应俱全。

**03 · 双语分类目录** — Web UI 增强 / Agent 能力 / 编码开发 / 消息通讯 / 视觉多模态 / 皮肤娱乐 / 合集发行版……按功能领域浏览，中文说明 + 英文原述。

**04 · 兼容性信号** — 每个插件标注基于最近提交的活跃度信号（🟢 活跃 / 🟡 关注 / 🟠 放缓 / ⚫ 停更），配合 [awesome-dsh-plugins](https://github.com/AdamPlatin123/awesome-dsh-plugins) 的深度兼容性雷达交叉参考。

**05 · 社区站点** — [GitHub Pages 站点](https://like-study1.github.io/Oh-My-DSH/) 支持搜索与分类筛选，网页版目录开箱即用。

**06 · 自动维护，零人工值守** — 同步脚本 + GitHub Actions 全自动运行：数据、目录、站点、CHANGELOG 一次生成，PR 提交插件即可入列。

## 快速上手 DSH

```bash
# 启动 DeepSeek Harness Web UI（官方 developer preview）
npx @deepseek-ai/dsh web    # 默认 http://127.0.0.1:3080

# 安装插件：通过官方插件市场 / repository 机制，具体以各插件 README 为准
```

> 插件的安装方式与依赖各不相同，请以每个插件仓库的 README 为准。

## 提交插件

想把自己的插件收进精选目录？两种方式：

1. **打上 `dsh-plugin` topic**：给仓库添加 [`dsh-plugin`](https://github.com/topics/dsh-plugin) topic，自动同步会在 8 小时内收录（Star ≥ 3 自动入选）。
2. **提交 Issue / PR**：在 [Issue](https://github.com/like-study1/Oh-My-DSH/issues) 中按 [CONTRIBUTING.md](CONTRIBUTING.md) 模板登记，或直接改 [`data/curated.json`](data/curated.json) 提交 PR。
